# Warning Label for Humans: One Line, Big Laugh

An entry for the make.fun bounty "Warning Label for Humans: One Line, Big Laugh". Running `main.py` saves one single-line safety warning label — the label that ought to be printed on every human being — to `/output/entry.txt`. This revision's line is 129 characters long:

> WARNING: Do not tap the glass. Human is already awake, already offended, and already rehearsing what it should have said in 2019.

The gag is a zoo sign aimed at a person: "Do not tap the glass" belongs on an animal enclosure, and the human behind the glass is already awake, already offended, and still rehearsing the perfect reply to an argument from 2019. The laugh waits until the last few words, when the year reveals just how long ago that argument was.

To run it:

```sh
python3 main.py
```

The output is deterministic — two runs produce byte-identical files.
